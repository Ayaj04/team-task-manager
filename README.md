# Team Task Manager

A modern full-stack Team Task Management web application built using React.js, Node.js, Express.js, PostgreSQL, and Prisma ORM.

The platform allows teams to create projects, assign tasks, manage workflow, track progress, and collaborate efficiently through a clean and responsive dashboard.

# ✨ Features

- User Authentication & Authorization
- JWT-Based Secure Login System
- Project Creation & Management
- Task Assignment & Tracking
- Responsive Dashboard UI
- Role-Based Access
- RESTful API Architecture
- PostgreSQL Database Integration

---

# 👥 Team Collaboration + Task Management

The application enables teams to collaborate effectively by organizing projects and tasks in a structured workflow.

Users can:

- Create projects
- Assign tasks to members
- Track project progress
- Update task status
- Manage workflow efficiently
- Collaborate through a responsive dashboard
